# Windows 0.20.6 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a Windows Warp-CN release aligned with the current macOS `0.20.6` version line.

**Architecture:** Reuse the existing Simplified Chinese source overlay as the single translation source of truth. Treat Windows as a platform packaging and validation lane: harden the Windows installer, build an OSS Windows executable installer, audit Windows-only UI strings, verify installation/runtime behavior, then publish release assets back to the same GitHub repository.

**Tech Stack:** Rust/Cargo MSVC build, PowerShell, Inno Setup 6, Python localization tooling, GitHub releases, GitHub PR checkpoints.

---

## Version Decision

The repository currently documents and releases macOS as `0.20.6`. If a prompt says `0.2.6`, treat it as a typo unless the repository version is intentionally changed. Windows release tags and asset names should use the `0.20.6` line, for example:

```text
0.20.6-cn-win.1
Warp-CN-0.20.6-cn-win.1-windows-x64-oss-unsigned.exe
```
